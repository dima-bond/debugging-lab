# Core investigation rubric

Assess each checkpoint across five observable parts:

| Part | Evidence of understanding |
|---|---|
| Observation | Describes what changes and how to reproduce it. |
| Tool choice | Picks a panel that can test the current hypothesis. |
| Evidence | Names a concrete request, timing, node, component, retained object, task, or trace event. |
| Causality | Connects the evidence to the user-visible symptom. |
| Verification | Repeats the same scenario and describes the before/after difference. |

Do not grade confidence, speed, or whether the learner guessed the answer. A correct guess without evidence is not mastery. Distinguish a missing explanation from an incorrect mental model, then ask one focused follow-up question.
